# 为什么这里没有预制 SMT2 数据集

此包用于指导 Codex 从真实应用生成实例。本轮没有运行应用工具链，因此没有把手写小公式标成“新工业实例”，也没有给未验证文件预设 SAT/UNSAT 标签。

实施时可以为查询提取器写少量 `crafted_demo` 测试，用来覆盖作用域、assumptions、理论检查和 UF 一致性。它们不得计入真实应用 benchmark 数量；应放在独立 tests/examples 目录。

张量读取 `X(a+i*s)`、正模数关系 `slot=q*R+r` 等是结构说明，必须连同原应用的完整前提、边界和待验性质导出，不能只把这些片段拼接就称忠实应用查询。
