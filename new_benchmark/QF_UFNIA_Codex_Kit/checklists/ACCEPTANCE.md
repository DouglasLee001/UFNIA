# 交付验收清单

请把每项标为 PASS / FAIL / NOT_RUN / NOT_APPLICABLE，并链接证据文件。

## 来源与复现

- [ ] 至少一条真实应用链路已完整运行；每条尝试路线有状态说明。
- [ ] 上游仓库完整 commit、输入文件、性质、工具/依赖版本已固定。
- [ ] 输入和导出物许可有依据；没有凭据或私有内容。
- [ ] 原始 solver 交互、真实命令、原始文件 hash 可取得。
- [ ] 有单实例、pilot、扩展命令；从干净环境可按说明重跑。

## 语义与理论

- [ ] 已包含完整性质反例公式/见证条件及当次 assumptions。
- [ ] push/pop/reset、声明作用域和 query_index 对应正确。
- [ ] parser/type checker 按目标逻辑通过；无额外理论。
- [ ] 每个主集实例有实际正元 UF 应用和有意义的整数非线性。
- [ ] 未删除量词、公理、数组或程序算术语义伪造 QF。
- [ ] div/mod 的符号和零分母语义、机器整数、NULL 等已核查。
- [ ] 忠实导出、应用派生、源层变异和演示分别统计。
- [ ] 有 UF/算术结构统计；未把有限 UF 可消除当作失败标准。

## 状态与范围

- [ ] 每个 status 有实际运行记录；未跑/超时保持 unknown。
- [ ] SAT 的断言检查/原应用回放状态已记录。
- [ ] UNSAT 的交叉检查或证明检查方式和限制明确。
- [ ] solver 分歧已隔离。
- [ ] 行数界、深度界、归纳子步骤等范围明确。

## 新颖性与发布

- [ ] 官方发布库和 staging 的精确版本、获取范围有记录。
- [ ] 原文件 hash、规范化结构 hash、应用身份、相似簇检查完成。
- [ ] 无改名复制、仅 seed 变化和未关联的同任务多编码。
- [ ] 未声称证明全库语义不等价；未完成部分明确。
- [ ] metadata 通过 schema，路径有效，最终文件 hash 对得上。
- [ ] REPORT 按来源/类别/状态/理论排除/阻塞列真实数量。
- [ ] 训练测试按任务族隔离，相关 mutant/修复/增量查询同组。
